# Power Switch 2.0.0

## 本版更新

- 全新紧凑 Fluent 风格 WinForms 界面，恢复原生标题栏、缩放、最小化、最大化和系统贴靠。
- 跟随 Windows 深浅主题、强调色及高对比度设置，支持 PerMonitorV2 DPI 缩放。
- 默认方案图标按列表顺序显示数字 **1、2、3、4**；已有自定义表情优先显示。
- 每个电源方案可独立选择彩色表情图标：点击左侧图标或聚焦卡片后按 F2，再在输入框按 **Win + . / Win + ;** 选择表情，也支持粘贴。
- 支持肤色、旗帜、职业、家庭等组合表情；按方案 GUID 保存，重启后保留，可恢复默认数字图标。
- 全局快捷键和“关闭窗口后驻留托盘”使用可保存开关；保存失败时恢复原设置并提示。
- 保留现有电源方案、Ctrl+Alt+数字快捷键映射、托盘切换、刷新和单实例；切换后核验系统实际状态，失败时保留确认过的选择并恢复控件。

## 下载和升级

下载附件 **PowerPlanSwitcher.zip**，退出旧程序后完整解压，运行 **PowerPlanSwitcher.exe**。

请将 **PowerPlanSwitcher.exe.config** 与 EXE 放在同一目录，以启用正确的 DPI 支持。升级时保留原有 **settings.ini**，继续使用已保存的偏好和表情图标。

系统要求：**Windows 10 / 11，.NET Framework 4.7.2 或更新版本**。无需安装，没有新增第三方依赖。电源方案和 Windows 的“电源模式”是不同设置，本程序切换系统已有方案，不创建或修改方案参数。

## 验证

已执行编译、服务逻辑、WinForms 界面/配置回归和彩色表情绘制检查。测试中电源切换使用模拟接口，实际系统集成检查只读取已有方案，不改变当前计划。

不同显示器的真实 DPI 切换、物理快捷键和 Windows 表情面板选词输入等人工验收边界，详见仓库中的验收说明。
